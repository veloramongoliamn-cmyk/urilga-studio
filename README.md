# Урилга Студи

Ерөөлтэй, дуутай, QR кодтой цахим урилгын сайт. Vercel дээр шууд байршина (тохиргоо шаардлагагүй).

- `index.html` — QR-аар нээгдэх нүүр хуудас (жишээнүүд, үнэ, захиалга)
- `<slug>/index.html` — 12 жишээ урилга
- `assets/` — зураг, дуу, ая
- `_build/` — сайтыг дахин үүсгэх скрипт: `python3 _build/build.py`
  - `events.py` — урилгуудын мэдээлэл
  - `build.py` — студийн утас, Facebook (STUDIO)

## Шинэ урилгад дуу, зураг нэмэх
`assets/voice-<slug>.mp3`, `assets/cover-<slug>.jpg` нэрээр хийгээд `python3 _build/build.py` ажиллуулна. Автоматаар холбогдоно.
